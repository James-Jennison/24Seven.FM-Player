# 24Seven.FM Player 0.1.0-alpha08

**Track:** Closed testing — Alpha  
**Version code:** 17  
**Status:** Prepared for signing; not yet uploaded

## What's new

- Adds native Android Auto browsing and playback through the existing Media3 playback service.
- Presents the approved five-station catalog in Android Auto: StreamingSoundtracks.com, 1980s.FM, Adagio.FM, Death.FM, and Entranced.FM.
- Supports Android Auto voice-search playback requests and reports media-library browse errors with Media3 session error codes.
- Preserves station artwork when Now Playing metadata has no artwork of its own.

## Validation recorded before signing

- The Android Auto catalog was accepted in the Android Auto Desktop Head Unit flow on an Android 16 Razr.
- The exact `main` source passed Android CI, including build, tests, and lint.
- `:app:compileDebugKotlin` and `:app:lintDebug` completed successfully; lint reported no errors.
- Release configuration keeps R8 code shrinking and Android resource shrinking enabled.
