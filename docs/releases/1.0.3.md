# 24Seven.FM Player 1.0.3

**Track:** Production feature update

**Version code:** 22

**Status:** In preparation. Not yet built, signed or submitted. The release announcer reads the short notes in [22.md](22.md).

**Source tag:** Not yet tagged

## What's new

- A redrawn launch screen: the 24seven.FM antenna mark pings, the on-air light blinks, and the mark settles into the
  station logo in the top bar.
- The Player describes itself as the network's official app, and shows the plain StreamingSoundtracks.com logo.
- Chat shows the stations' own smilies and emoji, and the composer has a smiley picker that lists the station's
  catalogue by tab and group.
- Now playing is read from the network's official feed, found through its published `station-feeds.json` registry,
  with the earlier station endpoint as the fallback and for requester and audience details.
- Chat has an Online now button in its top bar that opens the station's Online now list and members screen.
- Edit profile says when the station's own profile page is failing, rather than implying a problem with your account.
- Saving your profile sends the same `Origin` and `Referer` headers a browser does, and a refused save now names the station's HTTP answer.

### Fixes

- The smiley picker no longer crashes if a station page repeats a smiley code, group heading or tab.
- The launch-screen hand-off fades with its own timing instead of inheriting the move animation's.
- A chat message made only of smilies is confirmed against its own pictures, not any earlier picture-only message.
- Chat mention notifications are no longer repeated when the same message appears twice in one snapshot, and message
  fields containing separator characters can no longer be mistaken for one another.
- A request is no longer matched to a track on punctuation-only titles such as `!!!` and `???`.
- A registry that is down is not retried on every now-playing poll.

## Known station-side issue

Every station's Edit Profile page (`modules.php?name=Your_Account&op=edituser`) returned HTTP 500 with an empty page on
October 29, 2026, so profile editing cannot load until the station restores it. The Player's code path was not changed
for this release beyond the clearer message.

## Known cosmetic limitation

The launch-screen mark settles at a fixed top-left position. It matches the station logo on phones; on tablets it lands
near the navigation rail instead, and a right-to-left layout would send it away from the logo. It fades within about
0.4 seconds and was judged acceptable on the Razr 2023 and the Galaxy Tab S9 FE. Following the real logo position is
planned for the next release.
