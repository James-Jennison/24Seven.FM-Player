## What's new

- Brings the tested Alpha08 Android Auto and five-station playback foundation forward to the first production candidate.
- Adds the native onboarding guide and optional coach overlay from Release A.
- Adds consented, user-reviewed problem reports and bounded playback-start diagnostics from Release B.

- Corrects the native/public privacy disclosures for Google Cast's automatic encrypted anonymous interaction diagnostics.
