# 24Seven.FM Player 0.1.0-alpha02

Version code: 3  
Release stage: Closed-test update pending protected signing and Google Play upload

## Change

- Fix Issue #26: the song-request confirmation dialog now bounds its scrollable detail area so **Send request** and
  **Cancel** remain reachable when a long favorite-track title and the Android keyboard are present.

## Verification

- `:app:compileDebugKotlin` passed.
- The focused `requestConfirmationRemainsReachableAtMaximumTextScale` Android instrumentation regression passed on a
  physical Android 16 Motorola Razr. The regression enters an optional request message before asserting that
  **Send request** remains visible and actionable.

## Release boundary

This source candidate is not yet a Google Play-delivered build. It must be signed using the owner-held protected
recovery flow, uploaded to the active closed-test track, and installed through Google Play before Issue #26 can be
closed as fixed for testers.
