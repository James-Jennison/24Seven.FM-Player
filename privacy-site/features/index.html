Player essentials

The useful parts of listening.

One native Android Player for the five stations—without recreating the web listening experience each station already owns.

01

Playback that stays put.

Clear play and pause controls, now-playing information, and system media support for phones and tablets.

02

Context around the song.

Upcoming and recent tracks, history, and library search appear only where the selected station provides them.

03

Your station, your way.

Favorites, startup preferences, and station-aware features are kept clear without treating every station as identical.

04

Closed testing, clearly separate.

The first production release is under review by Google Play and is not yet available for public installation.

The invitation-only closed-testing program is separate from the production release under review.
